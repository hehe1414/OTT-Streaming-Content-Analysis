
# OTT Streaming Content Trend Analysis

## Project Overview
This project explores Netflix's content catalogue to understand
trends in movies and TV shows. The analysis was performed using
Python, Pandas, SQL and data visualisation libraries.

The dataset contains 8,807 records and 12 columns.

## Objectives
- Analyse the distribution of Movies and TV Shows.
- Identify the most popular genres.
- Study content release trends over the years.
- Identify the top content-producing countries.
- Understand content rating distribution.
- Analyse movie durations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Google Colab

## Key Findings

1. Movies account for 69.6% of the catalogue, while TV Shows
   account for 30.4%.
2. International Movies is the most popular genre.
3. The year 2018 recorded the highest number of releases,
   with 1,147 titles.
4. The United States contributes the highest number of titles,
   followed by India and the United Kingdom.
5. TV-MA is the most common content rating.
6. The average movie duration is 99.58 minutes.

## Visualizations
The project includes six visualizations:
- Movies vs TV Shows distribution.
- Top 10 popular genres.
- Content released over the years.
- Top 10 content-producing countries.
